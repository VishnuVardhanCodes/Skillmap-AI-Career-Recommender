# Create Project Structure Workflow

Purpose:
Generate folder and file structures for new projects.

Workflow Steps:

1. Identify project type.
2. Determine required folders.
3. Design modular file structure.
4. Generate recommended layout.
5. Suggest best practices.

Behavior:

- Follow clean architecture.
- Use scalable folder structure.
- Keep files modular.
- Ensure maintainability.

Trigger:

Use this workflow when:

/create-project <project-name>

Examples:

/create-project ecommerce-app
/create-project ai-chatbot
/create-project portfolio-website
