# Fix Bug Workflow

Purpose:
Detect and fix errors in code.

Workflow Steps:

1. Analyze the bug description.
2. Identify root cause.
3. Suggest fix strategy.
4. Generate corrected code.
5. Validate correctness.
6. Suggest prevention improvements.

Behavior:

- Debug logically.
- Maintain existing structure.
- Avoid breaking other features.
- Provide explanation of fix.

Trigger:

Use this workflow when:

/fix-bug <bug-description>

Examples:

/fix-bug login-error
/fix-bug api-timeout
/fix-bug null-pointer
