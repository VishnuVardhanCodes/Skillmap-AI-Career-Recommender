# Generate API Workflow

Purpose:
Create API routes and backend logic.

Workflow Steps:

1. Identify API purpose.
2. Define endpoint routes.
3. Create request and response models.
4. Generate controller logic.
5. Add validation logic.
6. Suggest improvements.

Behavior:

- Follow REST API standards.
- Use clean backend structure.
- Maintain proper error handling.
- Add comments for clarity.

Trigger:

Use this workflow when:

/generate-api <api-name>

Examples:

/generate-api user-service
/generate-api auth-api
/generate-api product-api
