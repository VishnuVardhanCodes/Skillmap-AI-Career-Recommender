# Project Development Workflow

Purpose:
Support development of AI-powered tools and automation systems.

Workflow Steps:

1. Analyze the project requirement.
2. Identify required components.
3. Design folder and file structure.
4. Generate modular and reusable code.
5. Add clear comments and explanations.
6. Suggest performance and scalability improvements.
7. Ensure maintainability of generated code.

Behavior:

- Prefer modular architecture.
- Use clean coding standards.
- Maintain structured logic.
- Optimize when possible.
- Think in production-level terms.

Trigger:

Use this workflow for:
- Building features
- Creating APIs
- Writing backend/frontend logic
- Designing automation systems
- Creating AI pipelines
