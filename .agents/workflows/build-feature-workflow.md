Description:
Build a new software feature with proper structure and modular design.

# Build Feature Workflow

Purpose:
Generate structured code for a new feature.

Workflow Steps:

1. Understand the feature name and requirement.
2. Identify required components.
3. Design file and folder structure.
4. Generate modular and reusable code.
5. Add meaningful comments.
6. Suggest improvements if needed.

Behavior:

- Follow clean architecture.
- Prefer modular design.
- Keep code readable and maintainable.
- Avoid unnecessary complexity.

Trigger:

Use this workflow when:

/build-feature <feature-name>

Examples:

/build-feature login-system
/build-feature payment-module
/build-feature dashboard-ui
