# General Assistant Workflow

Purpose:
Support general coding, debugging, and explanation tasks.

Workflow Steps:

1. Understand the user's request.
2. Break the task into smaller steps.
3. Provide structured solutions.
4. Generate clean and readable code.
5. Suggest improvements if possible.
6. Ensure correctness before completing.

Behavior:

- Respond step-by-step.
- Keep explanations structured.
- Use clear logic.
- Avoid unnecessary complexity.

Trigger:

Use this workflow when:

/assist <task>

Examples:

/assist explain recursion
/assist write sorting algorithm
/assist debug python code
